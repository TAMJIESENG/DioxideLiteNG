01 — 核心功能

五条能力线，

每个分类下的模块都能单独启停、单独设置、单独绑定按键。下面按分类说明这个客户端实际提供了什么， 以及每个模块的真实设置项（括号内取自源码，不是文案润色）。

02 — 界面

三套 GUI，六个 HUD，十套主题

ClickGUI 是唯一的功能入口：左侧选分类、中间列模块、右侧调设置。界面全部由客户端自绘， 因此风格、配色、动效都能整体替换。

05 — 上手使用

四步用起来

装好 jar、按一个键、开模块、调设置。状态自动保存，下次启动保持原样。

还没下载？先把 jar 拿到手 dioxideliteng-1.13.4-fabric.jar · 71,765,755 字节 · 放进 mods 目录即可，不需要安装程序。
下载1.13.4
STEP 01

放进 mods

把 dioxideliteng-1.12.0-mc26.3-fabric.jar 放进 versions\26.3-Fabric 0.19.5\mods，与 Fabric API 同级。

STEP 02

开面板

进游戏后按 RightShift 打开 ClickGUI（ClickGui 的默认键，可改）。

STEP 03

开模块 · 调设置

左侧五个分类，点模块右侧开关启停；点模块名在右栏调设置，滑块、模式、多选都在这里。

STEP 04

自动保存

开关与设置写入 state.json；HUD 位置可拖动，预设存进 configs 目录。

命令作用（来自 command/）
.bind把模块绑定到按键
.toggle直接开关某个模块
.config创建 / 读取 / 保存 / 删除预设
.friend管理好友名单
.say以客户端前缀发言
.help列出全部命令
PROFILE

状态与预设放在哪

模块状态读取自 versions\26.3-Fabric 0.19.5\dioxideliteng\state.json； 预设是 configs 目录下的独立文件，可在 GUI 或 .config 命令里切换。

命令前缀可以在 ChatCommands 模块里改成 . / - / ! / ' 之一。

依据 ClickGui.java（默认键 GLFW_KEY_RIGHT_SHIFT）、CommandManager.java（6 条命令）、 ChatCommands.java（前缀）、HudEditorScreen.java（HUD 拖动）、_tmp_extract/telly-grim-fix-patch/README.md（state.json 路径）。
